# Compose Template

A minimal Android project created from Android Studio's Basic Activity template and updated to use Jetpack Compose. Use it as a starting point for new Compose apps.

## Create a project from this template

1.  On GitHub, open this repository and select **Use this template** → **Create a new repository**.
2.  Give the new repository its own name and create it.
3.  Clone the new repository into a separate folder and open it in Android Studio.

Creating a repository with **Use this template** gives your project its own Git history and remote. Cloning this template repository directly would leave your project connected to the template repository.

## Customize the new project

- Change the app's displayed name in `app/src/main/res/values/strings.xml` (`app_name`).
- Change the package identifier in `app/build.gradle.kts` (`namespace` and `applicationId`), and update the Kotlin package declarations and source directory path to match.
- Change the Gradle project name in `settings.gradle.kts` if desired.

Then build and run the app from Android Studio to verify your changes.
